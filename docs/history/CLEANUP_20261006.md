# Repository cleanup — October 6, 2026

The owner approved this plan before execution. Phase 1 ran while gen54 was in
production. It touched nothing on gen54's pinned list, and gen54's full
identity was re-verified against its manifest after each step. Phase 2 waits
for gen54 to finish.

## Found during the survey: a pinned test had been edited

The October 5 CI fix added `@pytest.mark.local_artifacts` marks to
`tests/test_gen54_campaign.py` while gen54's iteration stage was running.

- That file is on gen54's `PINNED` list.
- `Campaign.stage` re-hashes the pins when a stage ends, so the running stage
  would have failed with "Inputs changed during stage".
- The working copy was restored to the exact pinned bytes: the LF form of
  commit `89ca5e7`, SHA256 prefix `b6605ba3`. gen54's whole identity then
  matched its manifest.
- The committed copy keeps the marks. They return to the working copy after
  gen54 completes.
